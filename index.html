Cosy Crafter — AI Crafting Companion
Product Designer / Developer  ·  Personal project, 2025
Figma AI interaction design Mobile app User flows Unity
+

Problem

Learning crochet and knitting without real-time support is difficult. Beginners commonly struggle to interpret patterns and correct mistakes however existing apps offer static tutorials but no responsive guidance.

Process

  • Mapped AI interaction pathways using a flow tree in Figma
  • Created scenario storyboards to define user journeys
  • Designed feature set and interface concepts in Figma
  • Built a working prototype in Unity with an integrated OpenAI agent

Design focus

Structuring conversational AI interactions so guidance feels natural and contextually useful. Designing intuitive flows between learning mode and active making.

What I explored

How AI companions can support hands-on creative tasks in real time, and what interaction patterns make that feel genuinely helpful rather than interruptive.

Outcome

Working Unity prototype with integrated OpenAI agent. Figma artefacts including flow tree, scenario storyboards, and interface concepts. Exploration of conversational AI in creative learning tools.

02
Hippocampus — VR Dementia Diagnostic Tool
CTO / Experience Designer  ·  2020–2021
User research Accessibility Healthcare UX Onboarding design Prototyping
+

Problem

Early dementia diagnosis relies on clinical tests that can be diffivult to administer onsite. Could immersive technology create a more intuitive and accessible diagnostic experience, particularly for elderly, non-technical users?

Process

  • Conducted research into user needs, behaviours, and accessibility requirements
  • Identified key barriers for non-technical users new to VR
  • Designed onboarding flows to reduce cognitive load and anxiety
  • Prototyped and iterated based on user testing and feedback

Design focus

Creating accessible interactions for users with no VR experience. Designing onboarding that felt reassuring rather than technical, with interactions that mapped to natural spatial behaviour.

What I explored

How VR can be designed for users who are anxious, unfamiliar with technology, or cognitively impaired — and how spatial memory tasks can be made intuitive through careful interaction design.

Outcome

Working VR prototype exploring spatial memory as a diagnostic tool. Early exploration of accessible VR in healthcare, with a focus on non-technical user onboarding and inclusive interaction design.

Experience Designer  ·  CampFR VR Residency, supported by HTC Vive
Spatial design Narrative UX VR Photogrammetry Tilt Brush
+

Overview

A VR project exploring storytelling through immersive environments. Investigating how spatial design and intuitive movement can support narrative engagement without traditional UI or on-screen instruction.

Design focus

  • How users engage with narrative in a VR format without explicit guidance
  • How spatial and visual cues can direct attention and support story

Outcome

Showcased at CampFR VR Residency, supported by HTC Vive. Explored how spatial composition can replace traditional UI in narrative-driven XR. Implications for accessible and instruction-free experience design.
